# Královské stezky – grafika

Obrázky pro webovou verzi hry Královské stezky (komunita Libri Civitatis). Web si je bere přes GitHub Pages:
`https://novakpa92-cz.github.io/kralovske-stezky-grafika/img/<název>.webp`

- `img/mesto-*.webp` – Kutná Hora (mapa a místa)
- `img/mapa-*.webp` – mapy oblastí výprav
- `img/vypravy/<oblast>-NN.webp` – místa na výpravách (číslo = pořadí místa v mapě hry)
- `*-m.webp` – zmenšená verze pro mobil

Malby vytvořeny v ChatGPT podle zadání v dokumentu „Královské stezky – zadání grafiky pro ChatGPT“.
