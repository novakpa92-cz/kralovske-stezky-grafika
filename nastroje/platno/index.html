⚔️ Plátno postavy

Vyber díl (kroužek) a nástroj níž, pak pracuj myší přímo na postavě. Nastavení se samo ukládá v prohlížeči. S helmou se vlasy nekreslí (jako ve hře).

Postava

Kolečko = přiblížit tam, kam míříš. Posun pohledu: pravé nebo prostřední tlačítko, nebo mezerník + tah. 0 = celá postava.

Měkký štětec
Hustotu můžeš měnit kdykoli, tvar sítě zůstane. Shift + tah = vyber víc bodů obdélníkem, Shift + klik = přidat/odebrat bod, pak táhni kterýkoli vybraný. Esc = zrušit výběr.
Q / E = natočit, Alt + kolečko = velikost, Shift + kolečko = šířka, Ctrl + kolečko = výška
